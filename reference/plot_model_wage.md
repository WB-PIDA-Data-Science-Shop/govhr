# Plot a wage model fit

Plot a wage model fit

## Usage

``` r
plot_model_wage(model_fit)
```

## Arguments

- model_fit:

  A `fixest` model object, as returned by
  [`model_wage()`](https://wb-pida-data-science-shop.github.io/govhr/reference/model_wage.md).

## Value

A `ggplot` object visualizing the model coefficients.
