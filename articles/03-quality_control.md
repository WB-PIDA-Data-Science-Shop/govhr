# Quality Control Report

``` r
library(govhr)
```

A full quality control report can be generated by passing all 3 modules
into the
[`generate_qc_report()`](https://wb-pida-data-science-shop.github.io/govhr/reference/generate_qc_report.md)
function as follows:

``` r
# Generate the quality control report
generate_qc_report(
  contract_dt = bra_hrmis_contract,
  personnel_dt = bra_hrmis_personnel,
  est_dt = bra_hrmis_est,
  output = "quality_control_report.html"
)
```
